# Administrar WhatsApp

En Administración › WhatsApp se conectan los números con el alta de Meta, se configura el bot de cada número (bienvenida, horario y menú), se arman los equipos y se crean las plantillas que aprueba Meta. Una plantilla aprobada no se edita: se duplica. Sin medio de pago, un número responde hasta 1.000 mensajes por mes y no manda plantillas ni difusiones.
