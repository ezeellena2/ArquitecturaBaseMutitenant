Extensiones técnicas de EF para filtros con nombre, orden y búsquedas. El filtro de tenant toma el contexto del acceso activo; los datos de plataforma no reciben ese filtro.
Leé: [multitenancy](../../../../docs/rules/multitenancy.md) · [paginado-y-busqueda](../../../../docs/rules/paginado-y-busqueda.md).
Copiá de `ModelBuilderExtensions.cs` para filtros con nombre y de `QueryableExtensions.cs` para listados.
