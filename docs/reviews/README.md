# Revisiones de arquitectura

Cada desarrollo terminado pasa una vez por la [revisión de arquitectura](../guides/revisar-arquitectura.md)
([ADR 0059](../decisions/0059-revision-de-arquitectura.md)). Su resultado va acá, en
`AAAA-MM-DD-arquitectura-<desarrollo>.md`, con los commits revisados, la matriz de los 36 criterios y los hallazgos.
Vale para esos commits: no se reescribe, y la reemplaza la revisión siguiente del mismo desarrollo.
