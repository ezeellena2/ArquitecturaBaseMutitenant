**Contradicciones que necesitan al usuario**
1. **«Cada empresa» (0012 y 0034).** ¿`AnyCompany` queda solo para el rol de sistema CompanyAdmin, o la API sigue dejando crear roles propios con ese alcance? Hoy se puede, y también desde la pantalla con `?scope=AnyCompany`. Según la respuesta se reescriben las dos ADR y los docs.
2. **`tools/` (0017).** ¿Se enmienda la 0017 («`tools/` solo para el soporte del E2E real, nunca para operar») o `RealE2ESetup` se muda a `tests/`?
3. **CI de contratos (0016).** ¿Se activa ya el checkout cruzado? Necesita que el CI del front pueda leer el repo del back, con un token si es privado. La otra opción es anotarlo en la E10.
4. **Respuestas HTTP (0002).** ¿Se acepta enmendar la 0002 para permitir `*HttpResponse` en Api/Contracts? Es técnica, pero contradice una ADR escrita.
5. **Auditoría de la organización.** Hoy muestra el correo actual de quien actuó, aunque ya no sea miembro (OrganizationAuditReader.cs:44-55). ¿Está bien, o para un ex miembro se muestra solo el nombre?
